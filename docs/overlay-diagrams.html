Route Discovery Overlay

Every host runs the daemon, on EC2 and on bare metal. Hosts find each other through an S3 registry (or a peers file you distribute), build GRE tunnels to each other, and run Babel over them. There are no separate relay instances: in each VPC, two of the ordinary hosts also relay for the others. When a path fails, Babel moves traffic to another one. The relaying hosts are each site's two hosts with the oldest registry entries that are still sending heartbeats. A new host never takes over; a relaying host is replaced after it misses 5 registry syncs (5 minutes by default), and takes the role back when it returns. With a peers file, they are each site's first two hosts in the file, and a dead one stays chosen until the file changes.
